## 📌 About The Project

**HexaResume** is a modern resume-building platform designed to make professional resume creation simple, accessible, and efficient.

Create, customize, preview, and export resumes using a collection of professionally designed templates — all through an easy-to-use interface.

Our mission is to help users present their skills, experience, and achievements with confidence.

---

## ✨ Key Features

| Feature | Description |
|---|---|
| 🎨 20 Resume Templates | Multiple designs for different professional needs |
| ✏️ Resume Editor | Easily add and customize resume information |
| ⚡ Live Preview | See changes while editing |
| 📄 PDF Export | Download completed resumes as PDF |
| 💾 Local Storage | Keep resume data saved locally |
| 🔍 Quality Checker | Review resumes for possible improvements |
| 📱 Responsive Interface | Designed for different screen sizes |
| 🛠️ Admin Panel | Administrative management |
| 📩 Contact Form | Contact and communication support |
